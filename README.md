# Little Chewz — editable teaching sources

Start with [START_HERE.md](START_HERE.md). AI editors follow [AGENTS.md](AGENTS.md), which holds every instruction in one generated file; paste it into any AI chat to brief it.

Teaching content lives in `content/`; resource links live in `catalog/`; shared rules live in `system/`. Templates cover the supported source types, and scripts validate sources and generate PDF previews. To create, revise or publish a resource, follow [Create](system/CREATE.md), [Update](system/UPDATE.md) or [Publish](system/PUBLISH.md). Approved generated-PDF release PRs use guarded Drive automation; ordinary merges do not publish.

See the [editing workflow](system/WORKFLOW.md), [tooling backlog](SYSTEM_IMPROVEMENTS.md), and [historical migration archive](archive/2026-10/README.md).
