# Little Chewz — editable teaching sources

Start with [START_HERE.md](START_HERE.md). AI editors follow [AGENTS.md](AGENTS.md).

Teaching content lives in `content/`; approved resource links live in `catalog/`; shared rules live in `system/`. Templates provide starting structures, and scripts check sources and generate PDF previews. Editing or merging source does not publish to Google Drive.
